# 构词法（Word Formation）

## 什么是构词法

构词法是指英语通过一定规则构成新单词的方法。

常见的构词法包括：

| 构词法 | 含义 | 示例 |
| --- | --- | --- |
| 派生构词法 | 在词根前后加词缀 | `happy → unhappy` |
| 合成构词法 | 将两个或多个单词组合 | `water + fall → waterfall` |
| 混合构词法 | 将两个词的一部分混合 | `breakfast + lunch → brunch` |
| 截短构词法 | 将单词的一部分截短 | `examination → exam` |
| 缩写构词法 | 用首字母或部分字母缩写 | `International English Language Testing System → IELTS` |
| 转化构词法 | 不改变词形，改变词性 | `fall (v.) → fall (n.)` |

---

# 一、派生构词法

## 1. 什么是派生构词法

派生构词法是通过在词根前添加**前缀**，或在词根后添加**后缀**，构成新单词的方法。

```text
词根：hydrate（水合）

hydrate + -n → hydration（水合作用）
hydrate + -ous → hydrous（含水的）
```

派生词常由以下部分组成：

```text
前缀 + 词根 + 后缀
```

```text
in- + visible
不可见的

in- + audible
听不见的

in- + edible
不能吃的
```

---

## 2. 词根

词根是单词中表达核心意义的部分。

```text
see → vis
hear → aud
eat → ed
```

加上后缀 `-ible` 后：

```text
vis + -ible → visible
可看见的

aud + -ible → audible
可听见的

ed + -ible → edible
可吃的
```

`-ible` 常表示“能够……的”：

```text
visible  = 能被看见的
audible  = 能被听见的
edible   = 能被吃的
```

注意：英语单词的拼写、读音和词根关系并不总是完全直观，记忆词根可以辅助理解，但不能机械套用。

---

## 3. 前缀

前缀位于词根前，常用于改变单词的意义。

```text
in- + visible → invisible
不可见的

in- + audible → inaudible
听不见的

in- + edible → inedible
不能吃的
```

### 常见否定前缀

| 前缀 | 含义 | 示例 |
| --- | --- | --- |
| `im-` | 不；非 | `impossible`（不可能的） |
| `in-` | 不；非 | `invisible`（看不见的） |
| `un-` | 不；非 | `unaccountable`（无法解释的） |
| `il-` | 不；非 | `illegal`（非法的） |
| `ir-` | 不；非 | `irregular`（不规则的） |
| `mis-` | 错误地；不当 | `mislead`（误导） |
| `dis-` | 不；相反 | `dislike`（不喜欢） |
| `de-` | 去除；向下；降低 | `dehydrate`（脱水） |
| `non-` | 非；不 | `non-linear`（非线性的） |

> `in-` 不一定表示否定，也可能表示“在……里面”。

```text
in + side → inside
在里面

in + adequate → inadequate
不充分的
```

同一个前缀可能有不同含义，要结合整个单词理解。

---

## 4. 后缀

后缀位于词根后，通常用于改变词性。

```text
visible → visibility
adj. 可见的 → n. 可见度
```

```text
suffix
suf- + fix
```

- `suf-`：在……之后。
- `fix`：固定、连接。

常见后缀示例：

| 后缀 | 常见作用 | 示例 |
| --- | --- | --- |
| `-ity` | 构成名词 | `visible → visibility` |
| `-able` / `-ible` | 构成形容词，表示“可……的” | `accept → acceptable` |
| `-al` | 构成形容词 | `structure → structural` |
| `-tion` | 构成名词 | `describe → description` |
| `-ly` | 构成副词 | `quick → quickly` |
| `-ness` | 构成名词 | `happy → happiness` |

---

## 5. 常见派生关系

```text
count (v. 数数)
→ countable (adj. 可数的)

work (v. 工作)
→ workable (adj. 可行的；可使用的)

accept (v. 接受)
→ acceptable (adj. 可接受的)

remark (v. 评论；注意到)
→ remarkable (adj. 非凡的；值得注意的)
```

注意：`-able` 和 `-ible` 都常表示“可……的”，但拼写没有绝对规则。

```text
credible   可信的
terrible   可怕的
possible   可能的
acceptable 可接受的
workable   可行的
```

不要只凭一个词根就猜测所有拼写形式；应结合常见词整体记忆。

---

## 6. 多个前缀或后缀

### 一个前缀、一个后缀

```text
construct（建造）
con- + struct

structure（建筑物；结构）
struct + -ure

construction（建造；建筑）
con- + struct + -ion
```

### 多个前缀或后缀

```text
reconstruct（再次建造）
re- + con- + struct

structural（结构的）
struct + -ure + -al

constructional（建筑的）
con- + struct + -ion + -al

reconstructionally（以重建的方式）
re- + con- + struct + -ion + -al + -ly
```

### 两个词根

```text
geostructure
geo- + structure
地质构造

geostructural
geo- + structure + -al
地质构造的

geostructurally
geo- + structure + -al + -ly
以地质构造的方式
```

---

## 7. 派生中的拼写变化

词根加词缀时，为了发音或拼写方便，可能发生省略、增加、重复或修改字母。

### 省略字母

```text
structure + -al → structural
```

- `structure` 加 `-al` 时，省略词尾的 `e`。

### 增加字母

```text
pent + gon → pentagon
```

- 两部分组合时，可能增加字母以便发音。

### 重复字母

```text
red + -ish → reddish
```

- `d` 重复，构成 `reddish`，表示“略带红色的”。

### 改变字母

```text
maintain + -ance → maintenance
describe + -tion → description
```

- 加后缀后，词形可能发生变化。
- 这些变化没有完全统一的规则，需要结合常见词进行积累。

# 二、合成构词法

## 1. 什么是合成构词法

合成构词法是将两个或多个独立单词组合起来，构成一个新词的方法。

```text
water + fall → waterfall
瀑布

water + proof → waterproof
防水的

under + water → underwater
水下的
```

合成词可以由不同词性组合而成。

| 构成方式 | 示例 | 含义 |
| --- | --- | --- |
| 名词 + 名词 | `water + fall → waterfall` | 瀑布 |
| 名词 + 形容词 | `water + proof → waterproof` | 防水的 |
| 副词 + 名词 | `out + break → outbreak` | 爆发 |
| 数词 + 名词 | `one + way → one-way` | 单向的 |
| 形容词 + 名词 | `high + class → high-class` | 高级的；一流的 |
| 介词 + 名词 | `before + hand → beforehand` | 事先；提前 |

> The road is one-way.  
> 这条路是单行道。

> Please tell me beforehand.  
> 请提前告诉我。

## 2. `-able` 词与合成词

有些词既可看作派生词，也可从合成角度理解。

```text
leg → legible
可读的

read → readable
可读的
```

两者都表示“可读的”，但侧重点不同：

- `legible`：字迹、印刷内容清楚，能够辨认。
- `readable`：文章、书籍等内容易读、通顺，或值得阅读。

```text
Your handwriting is legible.
你的字迹清楚，可以辨认。

This article is readable.
这篇文章通顺易读。
```

注意：并不是所有单词都有清晰的两种构词分析方法；很多词需要作为整体记忆。

# 三、混合构词法

## 什么是混合构词法

混合构词法是把两个词的部分字母或音节混合在一起，形成新词的方法。

通常取第一个词的前半部分，加上第二个词的后半部分。

```text
breakfast + lunch → brunch
早午餐

lunch + dinner → linner
午晚餐

smoke + fog → smog
烟雾

snow + ice → snice
雪冰混合物

smoke + haze → smaze
烟霾

website + seminar → webinar
网络研讨会

beat + beetles → Beatles
披头士乐队

service + game → sesga
服务型游戏公司
```

其中有些词较常用，如：

```text
brunch, smog, webinar
```

有些混成词较少见，可能只在特定语境、行业或创作表达中使用。

---

# 四、截短构词法

## 什么是截短构词法

截短构词法是把较长单词的一部分省略，形成较短、更口语化或更方便使用的词。

```text
airplane / aeroplane → plane
mathematics → math / maths
examination → exam
application → app
influenza → flu
refrigerator → fridge
```

常见特点：

- 截短词通常保留原词的核心含义。
- 很多截短词用于日常口语或非正式写作。
- 英式英语与美式英语的形式有时不同。

```text
math  → 美式英语常用
maths → 英式英语常用
```

---

# 五、缩写构词法

## 什么是缩写构词法

缩写构词法是选取多个单词的首字母或部分字母，构成较短形式的方法。

```text
very important person → VIP

International English Language Testing System → IELTS

Test of English as a Foreign Language → TOEFL

Radio Detection and Ranging → radar
```

### 常见读法

| 类型 | 示例 | 读法 |
| --- | --- | --- |
| 首字母缩略词 | `VIP`, `IELTS`, `TOEFL` | 通常逐个字母读 |
| 可作为单词读的缩写 | `radar` | 按一个完整单词读 |

---

# 六、转化构词法

## 什么是转化构词法

转化构词法是指单词形式不变，但词性发生变化。

```text
fall
v. 落下；减少；崩溃；降落
n. 瀑布；落下；秋天
adj. 秋天播种的；秋天成熟的；秋天用的
```

```text
educate（v. 教育）
→ education（n. 教育）
→ educator（n. 教育者）
```

注意：

- `fall` 属于**词性转化**，词形不变。
- `educate → education`、`educator` 是通过加后缀形成的新词，属于**派生构词法**。

更多转化例子：

```text
email (n.) → email (v.)
message (n.) → message (v.)
answer (n.) → answer (v.)
clean (adj.) → clean (v.)
```

> Please email me the document.  
> 请把文件通过电子邮件发给我。

> The room is clean.  
> 房间很干净。

> Please clean the room.  
> 请打扫房间。
