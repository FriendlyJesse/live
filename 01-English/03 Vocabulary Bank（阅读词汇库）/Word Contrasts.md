# Word Contrasts

## 缺点/不足

### Core map

| Word       | Core idea              | Typical use                                     | examples                                                                     |
| ---------- | ---------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------- |
| lack       | 完全没有或数量极少的匮乏状态         | - lack of experience<br>- lack of funds         | His explanation was rejected due a total lack of evidence.                   |
| shortage   | 数量满足不了实际需求的缺口          | - housing shortage<br>- labor shortage          | The factory had to cut production because of a severe raw material shortage. |
| scarce     | 因为某种资源在特定时期供不应求而难以寻觅   | - scarce resources<br>- make oneself scarce     | Food in the forest is scarce.                                                |
| deficiency | 达不到标准或健康需求所导致的内部缺陷与不达标 | - vitamin deficiency<br>- structural deficiency | The team lost the game due to a tactical deficiency in defense.              |

### Key contrasts

- 抽象状态与具体缺口的差异
	- **lack** 侧重于描述“从无到有”的**纯粹匮乏状态**，通常作为名词或动词，指代某物完全缺失或极其不足。
	- **shortage** 则侧重于**供需关系失衡产生的具体缺口**，通常用于社会、经济语境下某种可量化资源的短缺。
- 市场稀缺与内部缺陷的差异
	- **scarce** 是一个形容词，强调某种资源在市场或自然界中**客观存在的稀少与珍贵**，不容易得到。
	- **deficiency** 侧重于**内部系统的功能性缺陷或营养元素的不达标**，强调因为“少精少件”而未能达到完整、健康的法定标准。

### My memory summary

- **思维模型**：
	- **lack** 联想“空无一物的口袋”（完全没有）。
	- **scarce** 联想“荒漠中的水源”（极度稀缺，难以寻觅）。
	- **deficiency** 联想“体检报告单上的低指标”（功能不达标，有缺陷）。
	- **shortage** 联想“排长队的供货缺口”（供不应求）。

## 极好的 / 优秀的

### Core map

| Phrase       | Core idea                          | Typical use                                                              | examples                                                                                  |
| ------------ | ---------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| fantastic    | 极好的，极出色的；好到**令人难以置信或带有梦幻色彩**       | - fantastic opportunity<br>- fantastic idea                              | We had a fantastic time at the music festival last night.                                 |
| splendid     | 极好的，极佳的；带有**庄严、华丽或令人赞叹**的崇高感       | - splendid view<br>- splendid performance                                | The palace gardens offer a splendid view of the valley below.                             |
| terrific     | 极好的，了不起的；带有**极强情绪张力或力量感**的赞叹       | - terrific job<br>- terrific energy                                      | You did a terrific job on the presentation today.                                         |
| excellent    | 极好的，杰出的；达到极高质量或技术水准的**客观基准评价**     | - excellent quality<br>- excellent performance<br>- excellent reputation | The system demonstrated excellent stability during the high-concurrency pressure testing. |
| incredible   | 极好的，极美妙的；因**超出常理而令人惊叹、佩服**（侧重正面赞叹） | - incredible performance<br>- incredible speed                           | The new rendering engine processes graphics at an incredible speed.                       |
| unbelievable | 难以置信的；好（或坏）到**让人怀疑其真实性**（中性，极度夸张）  | - unbelievable price<br>- unbelievable accuracy                          | The accuracy of this predictive model is almost unbelievable.                             |

### Key contrasts

#### 情感色彩与主观体验的差异

- **fantastic** 带有强烈的**主观愉悦和惊喜感**，通常用于形容超出预期、好到像做梦一样的人、事、物或体验。
- **terrific** 是一种**情绪能量极强**的口语化赞美，用来表达对某人表现、能力或成果的极度认可，赞赏力度通常强于 _great_。
- **incredible** 虽然字面意思是“不可信”，但在现代英语中 **90% 以上都用于正面赞美**，形容事物极为出色、非凡，令人由衷赞叹。
- **unbelievable** 则是**完全中性且极度夸张**的词。它既可以形容好得过分（如 _unbelievable price_ 指价格便宜得不可思议），也可以形容坏得离谱（如 _unbelievable rudeness_ 极其无礼）。

#### 视觉美感与场景宏大度的差异

- **splendid** 侧重于描述**视觉上的壮丽、华贵或品质上的完美无瑕**，常用于形容风景、建筑、演出、礼仪等带有客观美感的事物。相比 _fantastic_ 和 _terrific_，它的语境更为正式、庄重。

#### 客观物理/技术评价指标

- **excellent**（高标准的客观事实，适合写进正式技术报告与业务评审）。

### My memory summary

共同点提炼

这组词均表示“极好的、极佳的”，属于赞美烈度极高的形容词。在日常与技术沟通中，它们可以用于对优秀的方案、出色的表现或绝佳的机会进行强烈的肯定。

**思维模型**：
- **fantastic** 联想“奇幻（fantasy）冒险”（好得令人难以置信、极其美妙）。
- **splendid** 联想“金碧辉煌的宫殿（splendor）”（画面壮丽、品质尊贵）。
- **terrific** 联想“火山爆发般的情绪迸发”（充满力量感和强烈的赞赏）。
- **incredible** 联想“超人/超级英雄（The Incredibles）”（能力强到超乎常人，令人赞叹）。
- **unbelievable** 联想“睁大眼睛、不敢相信的表情包”（真假难辨，好坏皆可）。
- **excellent** 联想“**质量检测合格章（Objective Premium）**”：代表符合最高标准的工业级品质。

## 小心

### Core map

| Phrase     | Core idea | Typical use | examples                                                                                                                                     |
| ---------- | --------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| be careful | 预防性警示/细心  |             | - Be careful with that boiling water.<br>- Be careful not to drop your new phone.<br>- You should be careful about what you say to the boos. |
| look out   | 即时危险/视线留意 |             | - Look out! There is a low branch ahead!                                                                                                     |
| watch out  | 即时危险/动作躲避 |             | - Watch out! That dog is going to bite!                                                                                                      |

### Key contrasts

#### 静态行为态度 VS 动态突发避险

- **be careful** 描述的是一种**状态（State）**。你可以对某人说 "_Always be careful when crossing the street_"（过马路要总是保持小心，属于长期叮嘱）。
- **look out / watch out** 描述的是一种**动作（Action）**。你只会在车子快撞上他时大喊 "_Watch out!_"，而不会在那个瞬间慢条斯理地说 "_Please be careful_"。

### My memory summary

- **be careful** = **Care（用心）**。做事情要“用心”，属于**防火防盗防犯错**的日常叮嘱，后面常接 **with / of / to do**。
- **look out** = **Look（看）**。大喊一声“看外面！”，用来提醒**眼睛能看到的即时障碍**。
- **watch out** = **Watch（警视）**。像守卫（Watcher）一样高度警惕，用来**躲避移动的危险（车、狗）或看不见的陷阱（骗子、小偷）**。

## 尽管

### Core map

| Phrase       | Core idea    | Typical use                                                        | examples                                                                                                                 |
| ------------ | ------------ | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| in spite of  | 让步 / 障碍      | - in spite of + noun/v-ing<br>- in spite of the fact that + clause | - We went for a walk in spite of the heavy rain.<br>- He passed the exam in spite of the fact that he didn't study much. |
| nevertheless | 转折 / 出乎意料的结果 |                                                                    | The weather was terrible. Nevertheless, we went for a walk.                                                              |

### Key contrasts

#### 语法词性不同（介词短语 vs. 连接副词）

- **in spite of** 是**介词短语**。它不能单独存在，后面**必须**直接跟名词、代词或动名词（$v\text{-ing}$）。它负责直接引出“障碍物”或“不利条件”。
- **nevertheless** 是**连接副词**。它用来连接两个完整的、独立的句子（主谓宾俱全）。它通常放在第二句的句首，后面必须加上逗号。

#### 在句子中的位置不同

- **in spite of** 的位置非常灵活，可以放在句首，也可以放在句中（例如：_In spite of the rain, we went out._ 或 _We went out in spite of the rain._）。
- **nevertheless** 几乎总是放在第二句的开头，用来引出逻辑的转折。

### My memory summary

- **in spite of** = **“尽管（后面直接加名词）”**。它就像一根**粘合剂**，把后面的困难名词（如 rain, illness）直接粘在主句上。
- **nevertheless** = **“然而 / 尽管如此（后面加完整句子）”**。它相当于高配版的 **however**。你必须先完整地把第一件事说完，点上句号或分号，然后再用它来开启第二句，表示“虽然前面说了这么多，但接下来……”

## 碰到

### Core map

| Phrase      | Core idea    | Typical use                                                                           | examples                                                                                                                                          |
| ----------- | ------------ | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| run into    | 偶然碰见 / 遭遇困境到 | - run into + sb.（偶然遇见）<br>- run into + trouble/debt/problems (陷入/遭遇)                  | - Guess who I ran into at the supermarket yesterday?<br>- If you don't plan budget well, you might run into debt.                                 |
| come across | 偶然发现 / 给人…印象 | - **come across** + sb./sth. (偶然发现/碰见)<br>- **come across as** + adj./noun (显得/给人…印象) | - I came across an interesting article while surfing the internet.<br>- She comes across as a very confident person in interviews.（她在采访中表现得非常自信。） |
| meet with   | 遭遇经历 / 会晤商谈  | - **meet with** + accident/refusal/failure (遭受/经历)<br>- **meet with** + sb. (与某人正式会面) | - The proposal met with strong opposition from the board.（该提议遭到了董事会的强烈反对。）<br>- The CEO is going to meet with the investors tomorrow.             |

### Key contrasts

#### 偶然遇见人 vs. 偶然发现物

- **run into** 的“碰到”多用于**人**（在街上肉体碰撞或无意遇见），如果用于物，通常是指“猛烈撞上”（如 _run into a tree_）。
- **come across** 的“碰到”多用于**物或人（尤其是书、资料、新奇小店）**，侧重于“无意中视线扫到”或“淘到、发现”的过程。

#### 遭遇抽象困境的区别（run into vs. meet with）

- **run into** 侧重于“**陷入 / 卷入**”某种持续性的不良状态（如 _run into debt_ 欠债、_run into trouble_ 陷入麻烦）。
- **meet with** 侧重于“**遭受到 / 迎头撞上**”某种具体的反作用力或突发事件（如 _meet with an accident_ 出车祸、_meet with refusal_ 遭到拒绝）。

### My memory summary

- **run into** = **“跑着撞上（Run + Into）”**。想象你跑步时在街角“撞见”老朋友，或者不小心“栽进”了债务和麻烦的坑里。
- **come across** = **“走着跨过（Come + Across）”**。想象你走着路，低头“偶遇”了一张百元大钞，或者在翻书时“无意间看到”一个生词。
- **meet with** = **“正式交锋（Meet + With）”**。带有“迎面碰上”的沉重感，用来指“遭受”车祸、拒绝、反对等严重阻力，或者用于商务上的“正式会晤”。
