# 形容词 adjective

## 形容词的用法

**形容词可以用于以下位置：**
- 定语
	- 前置定语
	- 后置定语
- 表语
- 补语
- 状语

### 用于定语

#### 前置定语

做定语的形容词一般放在要描述的对象之前，称这个定语为前置定语。

a ==hungry(前置定语)== rabbit.
一只饿了的兔子

a ==little white(前置定语)== rabbit
一只小白兔

a(限定词) ==beautiful(主观特征)== ==big(尺寸)== ==round(形状)== ==new(新旧)== ==black(颜色)== ==Chinese(来源)== ==wooden(材料)== table(用途)
一张崭新的漂亮的黑色中式木质大圆桌。

#### 后置定语

有时形容词只能后置作定语。

**如形容词修饰复合不定代词：**

| 不定代词       | 形容词修饰不定代词           | 意思      |
| ---------- | ------------------- | ------- |
| somebody   | somebody nice       | 某个好人    |
| anybody    | anybody absent      | 不在场的人   |
| everything | everything possible | 所有可能的事儿 |
| nothing    | nothing wrong       | 没有不对的事儿 |
**形容词短语一般会放在描述的对象之后作后置定语：**

carrots good for the rabbit
对兔子有好处的胡萝卜。

the rabbit ==eager(形容词)== to eat(动词不定式) carrots
= the rabbit that is eager to eat carrots
急于吃胡萝卜的兔子

the rabbit ==busy(形容词)== eating(动名词) carrots
= the rabbit that is busy to eating carrots
忙着吃胡萝卜的兔子

### 用于表语

系动词把系动词前面和系动词的后面练习起来，把后者表达的性质赋予前者。

The rabbit is(系动词) hungry(主语补语，表语).
兔子饿了。
#### 只做表语的形容词

如：以 a 开头的一些形容词，alive, asleep, alone

A rabbit is alive/sleep/alone. 兔子是活的/睡着的/孤单的
这些词一般不做定语 an ~~alive/sleep/alone~~ rabbit

a living/sleeping/lonely rabbit.
一只活着的/睡着的/孤独的兔子。

tips: alone 和 lonely 含义有差异，前者表示孤单单不一定难过，后者通常是孤独且难过。

某些情况下，这样的形容词可以做后置定语，但是比较少见：
the only rabbit alive
唯一一只活着的兔子。

它不能是：
~~the only rabbit alone~~
~~the rabbit alive~~

#### 只做表语的形容词：某些表身体状况的形容词

如： ill, well

The rabbit is ill/well.
兔子是健康的/生病的。

如果想做定语则要换词：
a sick rabbit/healthy rabbit.
一只生病的/健康的兔子。

### 用于补语

Carrots make rabbits happy(宾语补语).
胡萝卜让兔子开心。

### 用于状语

状语 = 给动作/事情添加背景信息的成分。

A rabbit came home, tired and hungry.
兔子回到家又累又饿。

## 形容词的构成

形容词分为：
- 简单形容词：hungry little white 之类简单的
- 复合形容器
	- 形容词 + 形容词/现在分词/过去分词
	- 副词 + 形容词/现在分词/过去分词
	- 形容词/数词 + 名词
	- 名词 + 形容词/现在分词/过去分词

### 复合形容词

#### 形容词 + 形容词/现在分词/过去分词

| examples                         | translate |
| -------------------------------- | --------- |
| a red(形容词)-hot(形容词) coal         | 一块红热的煤    |
| a good(形容词)-looking(现在分词) rabbit | 一只好看的兔子   |
| a new(形容词)-born(过去分词) baby       | 新生儿       |
#### 副词 + 形容词/现在分词/过去分词

| examples                 | translate |
| ------------------------ | --------- |
| all(副词)-round(形容词)       | 全面的       |
| hard(副词)-working(现在分词)   | 努力的       |
| recently(副词)-built(过去分词) | 最近建成的     |
#### 形容词/数词 + 名词

| examples                                           | translate |
| -------------------------------------------------- | --------- |
| white(形容词)-haired(名词)<br>...whose hair is white    | 白发的       |
| kind(形容词)-hearted(名词+ed)<br>...whose heart is kind | 好心的；善良的   |
tips: 
- 这样的形容词往往修饰人/动物，人/动物才有这种所有者数学。
- 第二个词：名词+ed 与动词过去式无关

若不是修饰人/动物，则不能转成 whose，也不能名词+ed：

| examples             | translate |
| -------------------- | --------- |
| a long-distance call | 长途电话      |
| a one-way street     | 单行街道      |
#### 名词 + 形容词/现在分词/过去分词

| examples                                                            | translate |
| ------------------------------------------------------------------- | --------- |
| a snow(名词)-white(形容词) rabbit<br>a rabbit that is white like snow    | 一只雪白的兔子   |
| a carrot(名词)-eating(现在分词) rabbit<br>a rabbit that that eats carrots | 一只吃胡萝卜的兔子 |
| a hear(名词)t-broken(过去分词) rabbit<br>a rabbit whose heart is broken   | 一只心碎的兔子   |

## 形容词的比较级和最高级

### 形容词比较级和最高级的构成

more beautiful 更漂亮
Magic mirror on the wall, who is the fairest(形容词最高级) one of all?
魔镜魔镜告诉我，谁是世上最美的人？

一般地，形容词比较级/最高级，直接在形容词词尾加 `er/est`：

| 正常             | 比较级                  | 最高级                  | 解析                            |
| -------------- | -------------------- | -------------------- | ----------------------------- |
| long 长         | longer 更长            | longest 最长           | +er/est                       |
| tall 高         | taller 更高            | tallest 最高           |                               |
| late 迟         | later 更迟             | latest 最迟            | e 结尾，+r/st                    |
| large 大        | larger 更大            | largest 最大           |                               |
| happy 快乐       | happier 更快乐          | happiest 最快乐         | 辅音字母+y结尾的词，把 y 变成 i，再加 er/est |
| busy 忙         | busier 更忙            | busiest              |                               |
| big 大          | bigger 更大            | biggest 最大           | 重度闭音节单词，先双写词尾的辅音字母再加 er/est   |
| fat 胖          | fatter 更胖            | fattest 最胖           |                               |
| interesting 有趣 | more interesting 更有趣 | most interesting 最有趣 | 多音节词/部分双音节词词前加 more/most      |
| difficult 难    | more difficult 更难    | most difficult 最难    |                               |
| good 好         | better 更好            | best 最好              | 不规则变化                         |
| bad 坏          | worse 更坏             | worst 最坏             |                               |
| many 多         | more 更多              | most 最多              |                               |
| little 少       | less 更少              | least 最少             |                               |
### 形容词比较级的用法

常见用法：

| examples                                         | translate       | explain   |
| ------------------------------------------------ | --------------- | --------- |
| This carrot is bigger than that one.             | 这根胡萝卜比那根大。      | 比...更...  |
| This carrot is there times bigger than that one. | 这根胡萝卜比那根大三倍。    |           |
| This carrot is as big as that one.               | 这根胡萝卜根那根胡萝卜一样大。 | 和...一样... |
| This carrot is three times as big as that one.   | 这根胡萝卜是那根的三倍那么大。 |           |
#### 越来越...

语法：`比较级 + and + 比较级`

prettier and prettier 越来越漂亮
more and more beautiful 越来越漂亮

但是不能说：
~~more and more prettier~~
~~beautiful and beautiful~~
~~more beautiful and more beautiful~~

The rabbit is smarter and smarter.
兔子越来越聪明了。

#### 越...(原因)，就越...(结果)

语法：`the + 比较级(原因)+补充内容, the + 比较级(结果) + 补充内容`

The more carrots the rabbit eats, the smarter he will become.
（假设）兔子吃胡萝卜越多，就会变得越聪明。

The more carrots he rabbit ate, the smarter he became.
兔子吃了越多胡萝卜，变得越来越聪明。（过去）

有时候也可以省略，全靠语境：
The more, the better. 越多越好

### 形容词最高级的用法

**最高级要实现设定的一个范围，如 in+地点，of+所属范围：**
Magic mirror on the wall, who is the fairest one of all?

**最高级前面加序数词表示第几：**
Magic mirror on the wall, who is the second fairest one of all?
魔镜魔镜告诉我，谁是所有人当中第二漂亮的女人？

**形容词最高级在修饰名词前面一般都加 the，如：**
Snow White is the most beautiful woman in the world.
白雪公主是世上最漂亮的女人。

The Queen is a most beautiful woman.
= The queen is a most beautiful woman.
皇后是一位非常漂亮的女人。
