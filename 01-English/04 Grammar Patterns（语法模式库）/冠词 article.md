# 冠词 article

## 🔤 不定冠词 a / an

### 🏗️ Structure

- a/an + 单数可数名词

**tips：**
- a: 用于辅音音素前
- an: 用于元音音素前
⚠️ 看读音，不看首字母

**examples：**
- a rabbit
- an apple
- a university（辅音）
- an hour（元音）

### 💡 Usage

| 用法       | 例子                                                                                                     | 记忆点                    |
| -------- | ------------------------------------------------------------------------------------------------------ | ---------------------- |
| 泛指某一个人或物 | I saw **a rabbit**.                                                                                    | 我看见了一只兔子；不强调具体是哪一只     |
| 泛指某一类    | **A rabbit** is an animal.                                                                             | `a/an + 单数名词` 可指一整个类别  |
| 表示数量“一”  | I gave you **a hundred** carrots.                                                                      | `a hundred` = 一百       |
|          | I eat 10 carrots **a day**.                                                                            | `a day` = 每天，不是单独表示“一” |
| 主谓一致     | He is **a teacher and video creator**.                                                                 | 一个 `a`：通常指同一个人         |
|          | **A teacher and a video creator** are here.                                                            | 两个 `a`：通常指两个人；谓语用复数    |
| 固定表达     | have **a** good time: 玩得开心<br>as **a** result: 因此；结果<br>in **a** hurry: 匆忙地<br>all of **a** sudden: 突然 |                        |

## 🔤 定冠词 the

### 💡 Usage

| 用法       | 例子                                                            | 记忆点                                        |
| -------- | ------------------------------------------------------------- | ------------------------------------------ |
| 特指       | Please give me **the carrot**.                                | 双方知道是哪一根胡萝卜                                |
| 再次提及     | I saw **a rabbit**. **The rabbit** ran fast.                  | 首次 `a/an`，再次 `the`                         |
| 序数词前     | **the first** rabbit                                          | `the + 序数词`                                |
| 形容词的最高级前 | **the biggest** carrot                                        | `the + 最高级`                                |
| 独一无二的名词前 | **the sun / moon / earth / Great Wall**                       | 公认唯一的事物                                    |
| 乐器       | play **the piano / guitar / violin / flute**                  | 表示“演奏某乐器”                                  |
| 类别泛指     | **The computer** has changed our way of life.                 | `the + 单数名词` 可泛指整类；更常用 `Computers ...`     |
| 用在形容词前   | the rich<br>the poor<br>the elderly                           | `the + 形容词` = 一类人；谓语用复数：`The rich are ...` |
| 固定表达     | all **the** time<br>by **the** way<br>out of **the** question | 固定搭配，不能省略 `the`                            |

## 🔤 零冠词

定义：名词前不用冠词的情况。

### 💡 Usage

#### 复数泛指

| 类型       | Structure  | Example                                                                                      |
| -------- | ---------- | -------------------------------------------------------------------------------------------- |
| 复数可数名词泛指 | 复数名词 + 谓语  | Rabbits are smart.<br>兔子这一类动物很聪明<br>Computers have changed our way of life.<br>计算机这一类事物改变了生活 |
| 不可数名词泛指  | 不可数名词 + 谓语 | Water is important.<br>水总体而言很重要<br>We breathe air.<br>我们呼吸空气                                 |

#### 泛指“概念”

| 用法             | 例子                                                                                                                                        | 说明                                                                             |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 学科、语言、球类、季节名称前 | I like **geography(泛指地理这一概念)**.<br>我喜欢地理。<br>I want to play **football(泛指足球运动)**.<br>我想踢足球。<br>Summer is hot. Winter is cold.<br>夏季热，冬季冷。 | geography 表示学科概念<br>football 表示学科运动<br>Summer、Winter 不是泛指某一个夏天或冬天，而是指所有的夏季和冬季。 |
| 季节、月份、星期前      | in spring; in August; on Monday                                                                                                           | 通常不加冠词                                                                         |
| 节日、国庆日等前       | on National Day                                                                                                                           | 专有节日名称前通常不加冠词                                                                  |
| 人名、地名等专有名词前    | Papa Rabbit                                                                                                                               | 通常不加冠词                                                                         |

#### 固定表达

- from time to time：不时地
- face to face：面对面地
- out of question:毫无疑问的
