# 招聘要求

## 全栈主管的招聘要求

### 岗位职责

-  **软硬件架构：** 具备 **Web 硬件交互架构** 选型能力，精通 **WebHID 直连** 与 **Go 本地代理服务**（**Go** + **WebSockets** / **gRPC**）在不同工业/硬件场景下的安全性与性能调优。
- **架构设计与演进**：负责系统整体架构设计，主导 **Go** 后端服务与 **Vue 3 + 无界微前端** 前端基座的解耦与高效协同。
- **上位机 UI 体系设计**：主导电竞外设上位机 **Design System** 的搭建，基于 **shadcn-vue** 与 **Tailwind CSS** 打造可复用的极客风格组件库，规范 **无界 (Wujie)** 微前端环境下的样式与主题统一。
- **团队管理与规范**：带领 **5-10 人** 研发团队，制定代码规范、Git 工作流以及代码审查（Code Review）标准，提升团队整体产出质量。
- **微前端体系建设**：负责 **主应用 (Base App)** 的搭建与 **子应用 (Sub App)** 的拆分，调优微前端运行环境，解决跨应用状态共享、路由同步及样式隔离等难题。
- **核心业务攻坚**：主导高并发、高可用后端服务的开发与性能调优，保障数据一致性与系统稳定性。
- **工程化与 DevOps**：协同推进 CI/CD 自动化流水线建设，优化打包构建与容器化部署流程。

### 任职要求

- **经验背景**：计算机相关专业本科及以上学历，具备 **5 年以上** 全栈或后端开发经验，且具备 **2 年以上** 研发团队管理经验。
- **后端能力**：精通 **Go** 语言，深入理解内存管理及高并发编程；熟练掌握 **Gin** / **Fiber** / **gRPC** 等常用框架；精通 **PostgreSQL** 或 **MySQL** 及 **Redis** 的索引优化与架构设计。
- **前端能力**：深入理解 **Vue 3** (Composition API) 响应式原理与 **TypeScript**；精通 **无界微前端 (Wujie)** 的核心运行机制（如 **Web Components**、**Shadow DOM**、**iframe** 组合沙箱），具备大型前端工程化落地方案经验。
- **UI体系：** 深入理解 **Design Tokens** 与无样式组件库（Headless UI）架构，具备企业级 UI 组件库设计及微前端样式隔离治理经验。
- **运维与架构**：熟悉 **Docker**、**Kubernetes (K8s)** 容器化技术，具备 **Nginx** 反向代理及微前端路由转发配置经验。
- **外设领域经验：** 熟悉电竞外设（如高回报率鼠标、电竞键盘、音频控制器）的业务逻辑，理解 **DPI 曲线设置**、**LOD (静默距离)**、**宏按键 (Macro)** 及 **RGB 动态灯效** 的数据传输机制者优先。
- **底层通信：** 精通 **WebHID** / **WebUSB** 协议，熟练处理二进制数据结构（**ArrayBuffer**、**TypedArray**），具备**固件升级**容错设计经验。
- **软实力**：具备极强的业务理解能力、技术决策力及跨部门沟通协调能力。


## 前端工程师的招聘要求

### 岗位职责

- **业务模块研发**：基于 **Vue 3** + **TypeScript** 完成微前端体系下各子应用及主应用核心功能的开发与维护。
- **微前端适配**：负责子应用在 **无界微前端 (Wujie)** 环境下的接入、生命周期管理与主子应用通信逻辑实现。
- **组件化与性能优化**：参与企业级 UI 组件库的维护，优化页面首次加载速度（FCP）、内存占用与渲染性能。
- **高效协同**：与 **Go** 后端工程师紧密配合，协同定义标准 RESTful API 及 WebSockets/gRPC 协议，保障前端数据流转顺畅。

### 任职要求

- **经验背景**：具备 **3 年以上** 前端开发经验，有大型单页应用（SPA）或微前端实际项目落地经验。
- **硬件交互：** 熟悉 **WebHID API** 或 **WebUSB API**，掌握二进制数据（**ArrayBuffer** / **DataView**）读写与 **HID 报告** 解析者优先。
- **核心技术栈**：精通 **Vue 3** 全家桶（Vue Router、Pinia）、**TypeScript**；熟练使用 **Vite** 进行构建配置与打包优化。
- **UI体系：** 熟练掌握 **shadcn-vue**、**Tailwind CSS** 或 **Element Plus**，具备无样式组件（Headless UI）改造与复杂视觉交互的二次开发能力。
- **微前端技术**：理解 **无界微前端 (Wujie)** 框架的实现原理，掌握 **CSS 样式隔离**、**JS 沙箱机制** 以及资源预加载策略。
- **工程素养**：具备良好的代码规范意识，熟练使用 Git，理解前端单元测试及自动化构建流程。
- **协作能力**：了解一门后端语言（Go / Java / Python / .Net / Rust）基本开发逻辑或具备 Node.js 中台开发经验者优先，具备良好的问题排查与技术攻坚能力。
- **加分项：** 具备电竞外设（如鼠标/键盘配置器）、**上位机驱动** 或 **Web 蓝牙 (Web Bluetooth)** 项目实际落地经验。
